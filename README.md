# HCM Lite (HR Management Web App)

Saylani Hackathon, HCM Lite Beginner Track ke liye bana project.
Ye ek simple HR web app hai jis mein Admin company aur employees ko manage karta hai,
aur employees attendance, leave aur salary slip dekh sakte hain.

**GitHub repo:** (yahan repo link likhein)

## Features

- **Setup:** pehli baar company aur Admin account banana.
- **Login / Logout:** Admin aur Employee ke alag roles, aur password change.
- **Employees (Admin):** add, edit, delete, search aur department filter. Naye employee ka login bhi banta hai.
- **Company settings (Admin):** office start time, grace minutes, leave quota, working days.
- **Attendance (Employee):** check-in aur check-out. Late aur half day ke rules Admin ki settings se.
- **Leave:** Employee apply karta hai, Admin approve ya reject karta hai (comment ke saath). Quota aur overlap check hote hain.
- **Dashboards:** Admin ko company ka khulasa aur attendance records. Employee ko is mahine ki summary.
- **Payslip:** monthly salary slip, deduction ke saath. Print ya PDF save ho sakti hai.
- **Responsive:** phone aur computer dono par chalta hai.

## Technology

- HTML, CSS aur JavaScript (koi framework ya backend nahi)
- Data browser ke localStorage mein save hota hai
- Font: Poppins (Google Fonts)
